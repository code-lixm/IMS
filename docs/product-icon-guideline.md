# IMS Product Icon Guideline

## Product Signal

IMS 是候选人管理工作台，不是消费类社交产品，也不是营销型 AI 工具。
图标需要传达：

- 结构化
- 冷静
- 专业判断
- 桌面工作台
- AI 辅助，但不能有夸张的科幻感

## Visual DNA From `design.pen`

- 主色是钴蓝 `#0062FF`
- 背景是浅蓝灰、半透明白、弱渐变
- 形态偏几何、克制、精密
- 有轻微工程感：网格、分隔、秩序、层次
- 高级感来自材质和比例，不来自复杂装饰

## Icon Rules

### 1. Shape

- 优先使用单一强识别几何母体
- 可以使用六边形、圆角方块、分层面板、秩序化轨道
- 不要使用过于写实的人物、简历纸张、握手、对话气泡等俗套符号

### 2. Composition

- 图标必须在 32px 仍可识别
- 主体只能有 1 个核心符号，辅以 1 层结构暗示
- 不要同时塞入“人”“简历”“AI”“对勾”多个语义
- 优先表达“结构化判断中枢”，不是“招聘海报”

### 3. Color

- 以钴蓝和浅蓝白为主
- 可以有从浅雾白到冷蓝的弱渐变
- 避免高饱和多彩配色
- 避免纯黑底、霓虹、紫色 AI 风格

### 4. Texture

- 允许极淡高光、玻璃雾层、网格秩序感
- 纹理只能服务材质，不能抢主体
- 不要做重阴影、金属拟物、3D 卡通

### 5. Tone

- 更像专业桌面软件图标
- 不像创业公司默认六边形 logo 模板
- 不像“AI 助手”通用星光图标

## Recommended Directions

### A. Hex Command Core

- 以六边形为核心
- 内部加入简化的分层轨道或排序结构
- 传达“判断中枢”

### B. Structured Panel Mark

- 以圆角方块为主轮廓
- 内部是 2-3 层秩序化面板或标记轨道
- 更偏工作台

### C. Monogram With System Geometry

- 以 `I` / `M` 抽象为几何结构
- 避免直接做普通字母 logo
- 需要借助网格和秩序感让字母更像系统图形

## Reject List

- 蓝色纸张 + 对勾
- 人头剪影 + 文件
- 霓虹 AI 星芒
- 复杂等距插画
- 过圆润的消费级 app icon
- 单纯 lucide hexagon 直接放大
